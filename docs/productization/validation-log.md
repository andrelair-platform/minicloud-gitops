# External Validation Log — expert feedback on a single brick

Per `.claude/rules/productization.md` (level 4 of `synthetic-enterprise.md`). Recruit **5–20 real domain
people** to test ONE brick (~30 min). This is **expert validation**, a different + honest proof than
"production usage" — never claim the latter. Log each session (role, not PII).

| Date | Brick tested | Tester (role) | Feedback (workflow / UX / vocabulary / gaps) | Change made |
|---|---|---|---|---|
| _seed_ | Claims Workbench | _(e.g. claims adjuster)_ | _pending first session_ | — |

**How to run one:** pick a brick with a UI (Claims Workbench, the UW workbench, the AI assistant) → a
scripted 30-min task list → capture verbatim friction → one concrete change per strong signal → link the
change back here + to the proof-catalog (Communication / Business row).
